# AI Text Summarizer

A simple and effective **abstractive text summarization tool** built using Python and HuggingFace Transformers.  
It takes long text as input and generates a short, meaningful summary in natural language.

---

## 🚀 Features
- Abstractive summarization (new sentences, not copy-paste)
- Supports long text inputs
- Uses Transformer-based models (T5/BART/Pegasus)
- Easy to run — only one Python file

---

## 📂 Files
summarizer.py → main summarizer script
notes.txt → input text to summarize
.gitignore → ignores venv/cache files
README.md → project documentation


---

## ▶️ How to Run

### **1. Activate virtual environment (Windows CMD)**

### **2. Run the summarizer**

---

## 🧠 How It Works
- Loads a pre-trained transformer model
- Breaks long text into chunks
- Generates summaries for each chunk
- Merges them into one clean final summary

This approach produces **human-like summaries** instead of copying sentences directly.

---

## 📘 Example Output
Input: A long paragraph or article  
Output: A short 3–4 line summary capturing the main idea
